# Rania Ghorayeb — multilingual portfolio

A responsive, single-page portfolio based on the four-page PDF supplied in the conversation.

## Files
- `index.html` — page structure and portfolio content
- `styles.css` — responsive styling
- `script.js` — Turkish / English / Arabic language switcher
- `assets/` — images extracted from the supplied PDF

## Preview locally
Open `index.html` in a modern browser. Internet access is needed for the optional Google Fonts import; system fonts are used as fallbacks.

## Publish with GitHub Pages
1. Create a GitHub repository (for example `rania-portfolio`).
2. Upload **all files and folders** in this package. Keep `index.html` in the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The URL will appear on the Pages settings screen.

## Before publishing
Please review the English and Arabic translations, candidate title, party wording, contact details and all biographical details. The translations are draft translations of the Turkish source text and should be checked by a fluent speaker. The site is a web adaptation, not a pixel-identical PDF reproduction.
